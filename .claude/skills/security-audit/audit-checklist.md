### 严重级别判定速查

| 如果你看到… | 级别 | 因为… |
|------------|------|-------|
| 明文密码/API Key | 🔴 严重 | 直接可用 |
| `shell=True` + 用户输入 | 🔴 严重 | 命令注入 |
| `eval(user_input)` | 🔴 严重 | 代码注入 |
| 文件路径未防 `../` | 🟡 注意 | 路径遍历 |
| 硬编码用户路径 | 🟡 注意 | 信息泄露 |
| subprocess 无 `--` | 🟡 注意 | 参数注入 |
| `.gitignore` 缺失 `.env` | 🟡 注意 | 潜在泄露 |
| `str(e)` 暴露路径 | 🟡 注意 | 信息泄露 |
| 依赖已知 CVE | 🟡 注意 | 供应链风险 |
| `breakpoint()` 残留 | 🟢 低风险 | 调试代码 |
| 日志含详细路径 | 🟢 低风险 | 信息泄漏 |
